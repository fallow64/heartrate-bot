# heartrate-bot

A Discord bot that keeps one message updated with my live heart rate, read from an Apple Watch through [Pulsoid](https://pulsoid.net).

## Invite

[Add the bot to a server](https://discord.com/oauth2/authorize?client_id=1569210924693200937&permissions=93184&scope=bot)

It needs View Channel, Send Messages, Manage Messages, Embed Links and Read Message History.

> **Warning:** the bot permanently deletes every other message in its channel, including pins and existing history. It refuses to start unless the channel name contains `fallow`.
